# DQIX Randomizer 1.8.1

A fix release for 1.8. **If you started a new game on 1.8 and it froze at the very first battle, this is the fix.**

## How to use it

1. You need your own copy of the **European multilingual** ROM:
   `Dragon Quest IX - Sentinels of the Starry Skies (Europe) (En,Fr,De,Es,It).nds`
   - Serial `YDQP`, MD5 `3a63438fff7db282fa3133e8fd020e85`, 268,435,456 bytes.
   - The application checks the file and refuses any other release. No ROM is
     distributed here.
2. Run `DQIX-Randomizer.exe`. There is nothing to install. The first time, Windows
   SmartScreen may say "Windows protected your PC": the program is simply not
   code-signed. Click *More info*, then *Run anyway*, or build it yourself
   from the source.
3. Drop your ROM on the window, pick a seed (or keep the random one), choose a
   preset and click **Randomize**. The randomized ROM, its log and its patch
   are written together in a `DQIX-Randomizer-seed<seed>` folder next to your
   ROM.
4. Start a **new game** in your emulator (melonDS, or DeSmuME with the Dynamic
   Recompiler turned off).

The ROM never leaves your computer: the application works offline and sends
nothing anywhere. The same seed with the same options always gives exactly the
same game, so a seed and the list of options are all you need to share a run.

## What changes

- **Fixed: a new game froze at its first battle.** On 1.8, starting a new game
  froze the console at the prologue fight (the cruelcumber and the slimes, with
  Aquila), whatever the options. The secret boss added in 1.8 hooks into the
  battle code; that code sat in a part of memory that character creation
  replaces, and the prologue never restored it. The game now restores it at the
  start of every battle. Games loaded from a save were not affected, which is
  why the 1.8 tests (all from saves) did not catch it.
- Nothing else changes: the same seed with the same options gives the same game
  as 1.8 (only this fix differs in the ROM), the file layout is unchanged, and
  your 1.8 in-game saves keep working as they are.

## Known issues

- Tested on emulators only.
- **DeSmuME: turn off the Dynamic Recompiler.** With it on, the game can go to a
  black screen when a map loads (seen right after the first battle). With the
  recompiler off, or on melonDS, it plays through.
- A savestate made on a 1.7 ROM does not load on a 1.8 or 1.8.1 ROM: keep playing
  from your in-game save. A 1.8 savestate taken before the first battle of a new
  game keeps the old code: start again from the title screen.
- Recipe bookshelves: the game remembers each book read, not the recipes.
  On a save where a book was already read, its shelf teaches nothing new;
  start a new game to get the randomized recipes from every shelf.
